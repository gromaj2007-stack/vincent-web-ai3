# Vincent Web AI – Online-Gehirn Update

Die bestehende Oberfläche, Animationen, lokale Erinnerungen und Browser-Sprachausgabe bleiben erhalten.

## Schnellstart
1. Dateien aus diesem ZIP in das bestehende GitHub-Repository hochladen und vorhandene Dateien ersetzen.
2. GitHub Pages neu laden (bei Bedarf Website schließen und wieder öffnen).
3. Vincent lange drücken → **Online-Gehirn verbinden**.
4. Falls der Online-Anbieter eine Anmeldung verlangt, diese im Browser durchführen.
5. Vincent doppelt antippen und sprechen.

## Wichtige Grenzen
- Online-KI läuft über Puter.js. Keine eigene API-Key-Eingabe erforderlich, aber der Anbieter kann Anmeldung, Limits oder nutzungsabhängige Kostenmodelle haben. Vor Zustimmung Konditionen prüfen.
- Die Online-Stimme ist über Puter.js mit AWS Polly (Hans, de-DE) integriert; bei Problemen folgt Browser-TTS. Eine reale Funktionsprüfung auf Android und eine Garantie für dauerhaft kostenlose Nutzung sind nicht möglich.
- Online-Gesprächsinhalte und ausgewählte Erinnerungen werden an den Anbieter übertragen.
- Das bisherige lokale Qwen-Gehirn bleibt als Alternative erhalten.
- Eine Live-End-to-End-Prüfung gegen den Anbieter war hier nicht möglich.
