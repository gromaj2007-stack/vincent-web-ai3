Vivi – echter WebGL-3D-Prototyp (noch NICHT der finale identische Charakter)

Öffne index.html über eine HTTPS-Website wie GitHub Pages (oder einen lokalen Webserver).
Die Three.js-Bibliothek wird über jsDelivr geladen, daher ist eine Internetverbindung nötig.
Auf dem Bildschirm drehen und mit den fünf Emotionsknöpfen die Animationen ausprobieren.

Dies ist ein eigenständiger Test und verändert die bestehende Vivi-Website NICHT.
Die Figur besteht aus echten räumlichen 3D-Objekten mit beweglichem Kopf, Augen, Mund,
Haaren und Armen. Die Optik ist eine vereinfachte Annäherung, keine exakte Rekonstruktion
unseres 2D-Referenzbildes. Für eine wirklich identische 3D-Figur braucht es ein modelliertes
und geriggtes GLB/VRM-Asset.
